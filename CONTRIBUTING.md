# Contributing

Thank you for helping improve Backupstic.

1. Open an issue for substantial behavior or architecture changes.
2. Create a focused branch and keep secrets and runtime backup data out of it.
3. Add or update tests and documentation with the change.
4. Run `make check` and `make test` before opening a pull request.
5. Describe operational impact, compatibility concerns, and restore testing in
   the pull request.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue.
By contributing, you agree that your contribution is licensed under MIT.
